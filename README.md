# Mil Graus Ar-Condicionado

Site institucional para a **Mil Graus Ar-Condicionado**, revendedora autorizada de ar-condicionado. Projeto de Extensão 2 (GRUEXT2), IFSP Guarulhos, curso de Análise e Desenvolvimento de Sistemas, desenvolvido pela startup IFTechHub.

## Objetivo
Dar à empresa uma presença digital profissional: apresentar os serviços, facilitar o contato e o agendamento de visitas, e acompanhar as manutenções periódicas dos clientes.
